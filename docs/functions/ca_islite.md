# XLL_CA_ISLITE

**Availability:** stable.

Reports whether the selected ChemApp runtime identifies itself as a Lite/demo-capability library.

## Syntax

```excel
=XLL_CA_ISLITE([update_token])
```

## Returns

`TRUE` or `FALSE`.

## Example

```excel
=XLL_CA_ISLITE()
```

This is a runtime property, not a property of a DAT file.
