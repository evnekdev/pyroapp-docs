# XLL_CA_GET_CONSTITUENT_WEIGHTS

**Availability:** stable, open-DAT only.

Calculates molar masses for selected phase constituents from their component-basis stoichiometry.

## Syntax

```excel
=XLL_CA_GET_CONSTITUENT_WEIGHTS(datafile,phases,constituents,[update_token])
```

The phase and constituent arrays are paired.

## Returns

One numeric molar mass per pair.
