# XLL_CA_GET_CONSTITUENT_RANGE_COUNT

**Availability:** stable, open-DAT only.

Returns the number of thermochemical temperature ranges stored for selected solution-phase constituents.

## Syntax

```excel
=XLL_CA_GET_CONSTITUENT_RANGE_COUNT(datafile,phases,constituents,[update_token])
```

`phases` and `constituents` are paired arrays.

## Returns

One integer range count per requested constituent.
